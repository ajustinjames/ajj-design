# ajj-design Platform Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the existing design system to `hardline`, migrate package names and element prefixes from `ds-`/`@ajj` to `hl-`/`@ajustinjames`, and restructure CI/CD for a multi-system monorepo.

**Architecture:** Move `packages/tokens` -> `packages/hardline-tokens` and `packages/components` -> `packages/hardline-components`. Update published package names, custom element tag names, CSS custom property prefixes, live docs, Storybook, tests, CI, and release automation. Do not rename source directories/files such as `src/ds-btn/ds-btn.ts`, TypeScript class names such as `DsBtn`, or existing test/story filenames.

**Tech Stack:** pnpm workspaces, Lit Web Components, Style Dictionary, Storybook, Playwright, GitHub Actions

**Current repo state before executing:** The repo is pre-migration: packages still live at `packages/tokens` and `packages/components`, package names are still `@ajj/*`, and component/custom property prefixes are still `ds-`/`--ds-`.

**Commit policy:** Do not commit during the migration unless the human explicitly asks for commits. The per-task checkpoints below use `git diff`/verification commands, not `git commit`. If commits are requested, make them only after a task group verifies cleanly; suggested messages are listed near the end.

**Historical docs policy:** Do not rewrite old historical specs or prior plans under `docs/superpowers/specs/` or unrelated `docs/superpowers/plans/`. They intentionally describe older `ds-*` work. Final sweeps must target live code/config/docs only.

## Task 9: Replace Publish Workflow With Label-Driven Release Workflow

**Files:**
- Delete `.github/workflows/publish.yml`
- Create `.github/workflows/release.yml`

The release workflow runs only after a PR is merged into `main`. It parses exactly one release label in the form `<system>:<patch|minor|major>`. No release label means no publish. More than one matching release label is an error.

- [ ] **Step 1: Delete old publish workflow**

```bash
git rm .github/workflows/publish.yml
```

- [ ] **Step 2: Create `.github/workflows/release.yml`**

```yaml
name: Release

on:
  pull_request:
    types: [closed]
    branches: [main]

jobs:
  release:
    if: github.event.pull_request.merged == true
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          ref: main
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Parse release label
        id: label
        env:
          LABELS_JSON: ${{ toJson(github.event.pull_request.labels.*.name) }}
        run: |
          mapfile -t LABELS < <(printf '%s\n' "$LABELS_JSON" | jq -r '.[] | select(test("^[a-z][a-z0-9-]*:(patch|minor|major)$"))')
          if [ "${#LABELS[@]}" -eq 0 ]; then
            echo "No release label; skipping publish"
            echo "skip=true" >> "$GITHUB_OUTPUT"
            exit 0
          fi
          if [ "${#LABELS[@]}" -gt 1 ]; then
            printf '::error::Expected one release label, found: %s\n' "${LABELS[*]}"
            exit 1
          fi
          LABEL="${LABELS[0]}"
          SYSTEM="${LABEL%%:*}"
          BUMP="${LABEL##*:}"
          if [ ! -f "packages/${SYSTEM}-tokens/package.json" ] || [ ! -f "packages/${SYSTEM}-components/package.json" ]; then
            echo "::error::No package pair found for release system '${SYSTEM}'"
            exit 1
          fi
          echo "skip=false" >> "$GITHUB_OUTPUT"
          echo "system=${SYSTEM}" >> "$GITHUB_OUTPUT"
          echo "bump=${BUMP}" >> "$GITHUB_OUTPUT"

      - uses: pnpm/action-setup@v3
        if: steps.label.outputs.skip != 'true'
        with:
          version: 10

      - uses: actions/setup-node@v4
        if: steps.label.outputs.skip != 'true'
        with:
          node-version: '20'
          cache: 'pnpm'
          registry-url: 'https://registry.npmjs.org'

      - name: Install dependencies
        if: steps.label.outputs.skip != 'true'
        run: pnpm install --frozen-lockfile

      - name: Bump package versions
        if: steps.label.outputs.skip != 'true'
        id: version
        env:
          SYSTEM: ${{ steps.label.outputs.system }}
          BUMP: ${{ steps.label.outputs.bump }}
        run: |
          TOKENS_PKG="packages/${SYSTEM}-tokens/package.json"
          COMPONENTS_PKG="packages/${SYSTEM}-components/package.json"
          CURRENT=$(jq -r '.version' "$TOKENS_PKG")
          COMPONENTS_CURRENT=$(jq -r '.version' "$COMPONENTS_PKG")
          if [ "$CURRENT" != "$COMPONENTS_CURRENT" ]; then
            echo "::error::Package versions differ before release: tokens=${CURRENT}, components=${COMPONENTS_CURRENT}"
            exit 1
          fi
          IFS='.' read -r MAJOR MINOR PATCH <<< "$CURRENT"
          case "$BUMP" in
            major) MAJOR=$((MAJOR + 1)); MINOR=0; PATCH=0 ;;
            minor) MINOR=$((MINOR + 1)); PATCH=0 ;;
            patch) PATCH=$((PATCH + 1)) ;;
          esac
          NEW="${MAJOR}.${MINOR}.${PATCH}"
          TMP="$(mktemp)"
          jq --arg v "$NEW" '.version = $v' "$TOKENS_PKG" > "$TMP" && mv "$TMP" "$TOKENS_PKG"
          TMP="$(mktemp)"
          jq --arg v "$NEW" '.version = $v' "$COMPONENTS_PKG" > "$TMP" && mv "$TMP" "$COMPONENTS_PKG"
          echo "version=$NEW" >> "$GITHUB_OUTPUT"

      - name: Build packages
        if: steps.label.outputs.skip != 'true'
        env:
          SYSTEM: ${{ steps.label.outputs.system }}
        run: |
          pnpm --filter "@ajustinjames/${SYSTEM}-tokens" build
          pnpm --filter "@ajustinjames/${SYSTEM}-components" build

      - name: Commit and tag release
        if: steps.label.outputs.skip != 'true'
        env:
          SYSTEM: ${{ steps.label.outputs.system }}
          VERSION: ${{ steps.version.outputs.version }}
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add "packages/${SYSTEM}-tokens/package.json" "packages/${SYSTEM}-components/package.json"
          git commit -m "chore: release ${SYSTEM}-v${VERSION}"
          git tag "${SYSTEM}-v${VERSION}"
          git push origin main --follow-tags

      - name: Publish to npm
        if: steps.label.outputs.skip != 'true'
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
          SYSTEM: ${{ steps.label.outputs.system }}
        run: |
          if [ -z "${NODE_AUTH_TOKEN:-}" ]; then
            echo "::error::NPM_TOKEN secret is required to publish"
            exit 1
          fi
          pnpm --dir "packages/${SYSTEM}-tokens" publish --access public --no-git-checks
          pnpm --dir "packages/${SYSTEM}-components" publish --access public --no-git-checks

      - name: Create GitHub release
        if: steps.label.outputs.skip != 'true'
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          SYSTEM: ${{ steps.label.outputs.system }}
          VERSION: ${{ steps.version.outputs.version }}
        run: |
          gh release create "${SYSTEM}-v${VERSION}" --title "${SYSTEM} v${VERSION}" --generate-notes
```

- [ ] **Step 2: Create `scripts/create-system.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

usage() {
  echo "Usage: create-system.sh <name> <prefix>" >&2
}

NAME="${1:-}"
PREFIX="${2:-}"

if [ -z "$NAME" ] || [ -z "$PREFIX" ]; then
  usage
  exit 1
fi

case "$NAME" in
  *[!a-z0-9-]*|""|-*)
    echo "Error: name must be lowercase kebab-case and cannot start with '-'" >&2
    exit 1
    ;;
esac

case "$PREFIX" in
  *[!a-z0-9-]*|""|-*)
    echo "Error: prefix must be lowercase kebab-case and cannot start with '-'" >&2
    exit 1
    ;;
esac

REPO_ROOT="$(cd "$(dirname "$0")/.." && pwd)"

TOKENS_SRC="${REPO_ROOT}/packages/hardline-tokens"
COMPONENTS_SRC="${REPO_ROOT}/packages/hardline-components"
TOKENS_DEST="${REPO_ROOT}/packages/${NAME}-tokens"
COMPONENTS_DEST="${REPO_ROOT}/packages/${NAME}-components"

if [ ! -d "$TOKENS_SRC" ] || [ ! -d "$COMPONENTS_SRC" ]; then
  echo "Error: hardline template packages do not exist" >&2
  exit 1
fi

if [ -d "$TOKENS_DEST" ] || [ -d "$COMPONENTS_DEST" ]; then
  echo "Error: packages/${NAME}-tokens or packages/${NAME}-components already exists" >&2
  exit 1
fi

echo "Scaffolding ${NAME} from hardline template..."

cp -R "$TOKENS_SRC" "$TOKENS_DEST"
cp -R "$COMPONENTS_SRC" "$COMPONENTS_DEST"

rm -rf "${TOKENS_DEST}/dist" "${COMPONENTS_DEST}/dist"
rm -rf "${TOKENS_DEST}/node_modules" "${COMPONENTS_DEST}/node_modules"

# Find-replace order is load-bearing: longest patterns first.
find "$TOKENS_DEST" "$COMPONENTS_DEST" -type f \( -name '*.ts' -o -name '*.js' -o -name '*.json' -o -name '*.css' -o -name '*.html' -o -name '*.md' -o -name '*.yml' -o -name '*.yaml' \) -print0 |
  while IFS= read -r -d '' FILE; do
    perl -i -pe "
      s|\@ajustinjames/hardline|\@ajustinjames/${NAME}|g;
      s|--hl-|--${PREFIX}-|g;
      s|hl-|${PREFIX}-|g;
      s|hardline|${NAME}|g;
    " "$FILE"
  done

echo ""
echo "Done. Next steps:"
echo "  pnpm install"
echo "  pnpm --filter @ajustinjames/${NAME}-tokens build"
echo "  pnpm --filter @ajustinjames/${NAME}-components exec tsc --noEmit"
```

- [ ] **Step 3: Make executable and syntax-check**

```bash

bash -n scripts/create-system.sh
```

Expected: `bash -n` prints no output.

- [ ] **Step 4: Do not run the scaffold script as part of this migration**
